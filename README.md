🕌 Jamia Masjid – Prayer Times & Community Website
A modern, fully responsive, multilingual website template designed specifically for Mosques and Islamic communities. It features live prayer countdowns, a dynamic monthly timetable, Qibla compass, Zakat calculator, and a no-code Google Sheets backend so mosque staff can update the website without writing a single line of code.

🔗 Live Demo: https://aetherom.github.io/Mosque2/

GitHubGitHubGitHub

✨ Key Features
No-Code Management: Mosque staff update timings, announcements, and services directly via a Google Sheet. No coding required.
Multilingual Support: Full UI translation (English, Urdu, Bengali, Tamil) with custom text translation support for content.
Live Countdown: Real-time countdown to the next Jamaat.
Dark/Light Mode: Eye-friendly theme toggle with local storage memory.
Interactive Tools: Built-in Qibla Compass, Zakat Calculator, and Digital Tasbih.
Print & PDF: Clean, print-ready monthly timetables and PDF export.
Mobile First: Fully responsive design that works beautifully on all devices.
🛠️ Tech Stack
Frontend: HTML5, CSS3 (CSS Variables for dynamic theming), Vanilla JavaScript (Zero frameworks for maximum speed).
Backend: Google Sheets API (gviz/tq) for a free, easy-to-manage database.
Libraries: jsPDF for client-side PDF generation.
🚀 How to Setup (For Developers)
Clone or download this repository.
Open index.html in any code editor.
Find const SHEET_URL = 'PASTE_YOUR_SHEET_ID_HERE'; in the script section.
Replace it with your Google Sheet ID.
Upload to any hosting platform (GitHub Pages, Netlify, Vercel, or standard cPanel).
📊 Staff Management Guide
Included in this repository is the Website_Management_Guide.xlsx file. This file contains the exact structure required for the Google Sheet backend (Settings, Jan-Dec tabs, Announcements, etc.). Mosque administrators can use this file to manage the site daily.
